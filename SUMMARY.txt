================================================================================
RUNNING THE APP
================================================================================

1. Install dependencies:
   $ npm install

2. Start development server:
   $ npm start

3. Run on platforms:
   $ npm run android    # Android
   $ npm run ios        # iOS (Mac only)
   $ npm run web        # Web browser

4. Scan QR code with Expo Go app (mobile)
